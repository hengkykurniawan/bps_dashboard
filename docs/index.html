2 · Variabel

Galeri subjek

Setiap variabel dalam satu subjek digambar otomatis (periode terbaru). Grafik dimuat saat digulir agar tidak membanjiri API BPS.

File lokal

CSV tidy hasil bps_data.py / bps_chart.py di folder ini (tambah folder lain dengan --data-dir). Berguna saat offline.

Pengaturan

Kunci API tersimpan di .bps_key pada folder aplikasi dan tidak pernah dikirim ke halaman GitHub Pages.

Tentang

Sumber data sama dengan bps_download: webapi.bps.go.id (Tabel Dinamis). Bedanya, keluarannya grafik, bukan tabel.

Dua sumber data

ModeIsiSyarat
◐ Data tersimpan Cuplikan JSON yang ikut tersimpan di repositori, disegarkan berkala oleh GitHub Actions Tidak perlu apa pun — berjalan penuh di browser
● Data langsung Seluruh variabel BPS, periode apa pun, selalu terbaru Jalankan python bps_dashboard.py di komputer sendiri

Kunci API BPS tidak pernah ada di halaman ini. Mode tersimpan memakai data yang sudah diambil sebelumnya; mode langsung memakai layanan lokal yang menyimpan kuncinya sendiri. Jenis grafik ditentukan oleh kode yang sama (docs/infer.js) pada kedua mode.

Bagaimana jenis grafik dipilih?

Struktur variabelGrafik
1 seri, ≥3 periodeGaris
1 seri, ≤2 periodeBatang
2–8 komponen dari satu total, sepanjang waktuArea bertumpuk (100% bila berupa persen)
2–8 seri sepanjang waktuGaris ganda
9–16 seri sepanjang waktuPanel kecil
>16 seri sepanjang waktuHeatmap
1 seri, nilai +/− (mis. laju pertumbuhan)Batang divergen
1 seri, >8 kategori (mis. 34 provinsi)Batang horizontal berperingkat
2–8 komponen dari satu totalBatang bertumpuk
>8 seri × kategoriHeatmap

Warna kategori memakai 8 slot tetap yang sudah diuji aman untuk buta warna; lebih dari 8 seri tidak menambah warna baru — bentuk grafiknya yang berubah (panel kecil atau heatmap). Setiap grafik punya kembaran tabel lewat tombol “Tabel”.
