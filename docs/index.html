2 · Variabel

Galeri subjek

Setiap variabel dalam satu subjek digambar otomatis (periode terbaru). Grafik dimuat saat digulir agar tidak membanjiri API BPS.

File lokal

CSV tidy hasil bps_data.py / bps_chart.py di folder aplikasi (tambah folder lain dengan --data-dir). Hanya tersedia saat layanan lokal berjalan.

Kunci API BPS

Dengan kunci Anda sendiri, halaman ini mengambil data langsung dari webapi.bps.go.id — seluruh variabel, periode apa pun, selalu terbaru, tanpa perlu menjalankan apa pun. Ambil kunci gratis di webapi.bps.go.id/developer.

Kunci disimpan di localStorage browser ini saja dan hanya dikirim ke webapi.bps.go.id. Kunci tidak pernah masuk ke repositori dan tidak dibagikan ke pengunjung lain. Di komputer bersama, sebaiknya pakai layanan lokal (python bps_dashboard.py) agar kunci cukup tersimpan di berkas .bps_key.

Bagaimana jenis grafik dipilih?

Struktur variabelGrafik
1 nilai sajaAngka tunggal
1 seri, ≥3 periodeGaris
1 seri, ≤2 periodeBatang
2–8 komponen dari satu total, sepanjang waktuArea bertumpuk (100% bila berupa persen)
2–8 seri sepanjang waktuGaris ganda
9–16 seri sepanjang waktuPanel kecil
>16 seri sepanjang waktuHeatmap
1 seri, nilai +/− (mis. laju pertumbuhan)Batang divergen
1 seri, >8 kategori (mis. 34 provinsi)Batang horizontal berperingkat
2–8 komponen dari satu totalBatang bertumpuk
>8 seri × kategoriHeatmap

Warna kategori memakai 8 slot tetap yang sudah diuji aman untuk buta warna; lebih dari 8 seri tidak menambah warna baru — bentuk grafiknya yang berubah (panel kecil atau heatmap). Setiap grafik punya kembaran tabel lewat tombol “Tabel”. Baris agregat (mis. “INDONESIA”, “Jumlah”, “PDRB”) dideteksi dari nilainya dan dikeluarkan agar tidak dihitung dua kali.
